# PCB 热与功耗分布模块：首版设计与验收

## 目标和边界

首版接收板尺寸、等效面内导热系数、体积热容、双面换热系数和元件矩形功耗，计算稳态或瞬态板面温度分布，并输出热图视频和数值摘要。所有输入使用 SI 单位，温度输入和输出使用摄氏度，温差按 K 计算。示例参数仅用于演示，用户需要以实际叠层、铜覆盖率、安装和气流条件校准等效参数。

模型把 PCB 视为薄的二维等效热片。板厚方向温度梯度、铜箔走线的局部形状、过孔、散热器接触热阻、辐射、气流场和电路电流分布不在首版范围内。元件的 `power_w` 是用户提供的热耗散；模块不从电路图推算功耗。

该等效板面思路与 [COMSOL 的板级预估示例](https://doc.comsol.com/6.4/doc/com.comsol.help.models.heat.disk_stack_heat_sink/disk_stack_heat_sink.html) 一致：示例以均匀、各向异性的宏观 PCB 近似复杂叠层，并说明属性取决于层数、铜线密度和过孔。这里进一步压缩为单个厚度平均温度，因此不得把局部热点当成未经校准的器件结温。

## 数学模型

设板厚为 $d$，密度为 $\rho$，比热为 $c$，面内导热系数为 $k_x,k_y$。板面单位面积热容为 $C_A=\rho c d$，面内片导热系数为 $K_x=k_xd, K_y=k_yd$。板面温度满足

$$
C_A\frac{\partial T}{\partial t}
=\frac{\partial}{\partial x}\left(K_x\frac{\partial T}{\partial x}\right)
+\frac{\partial}{\partial y}\left(K_y\frac{\partial T}{\partial y}\right)
+q''-(h_\mathrm{top}+h_\mathrm{bottom})(T-T_\infty).
$$

元件功率按其矩形与网格单元的面积交集分配，总功率必须保持。板边界绝热。每个单元的离散能量收支由热容变化、面内通量、元件功率与上下表面对流组成。稳态移除热容项；无散热的正功率稳态问题没有有限解，应拒绝。

瞬态结果中的 `heat_rejection_w` 是终点时刻的有符号对流功率，`rejected_energy_j` 是整个时段的有符号对流能量；正值表示板向环境放热，负值表示环境向板供热。`stored_energy_j` 是板内能变化，三者与输入功耗共同构成能量校验。

## 接口和集成

- 输入结构见 [示例](../toolboxes/physics/pcb_thermal_demo.json)。`pcb_example`、`pcb_validate`、`pcb_prepare` 在现有 toolbox 的结构化 API 中提供；最终运行沿用宿主的 `physics_simulate` 执行入口，以保持现有 QQ 主机协议不变。
- 已准备模型带 `domain=pcb_thermal` 标签。现有机械场景仍走原有 `scene-v1` 路径；一个任务每次只能准备其中一个领域。历史模型也保留领域标签，续改时不得将 PCB 参数当作机械场景。
- 仓库中 PCB 数值代码与视频代码位于 toolbox 独立文件，现有机械求解器内核不改。构建器把新文件纳入发布哈希，registry 以内容摘要发布和激活。

## 研发验收门禁

1. **模型校验**：拒绝非有限值、负功耗、越界或退化的元件、非法网格和不适定稳态；限制规模和预算。
2. **解析与守恒**：均匀加热且初态均匀时，对比集总热容解析解；检查稳态总输入功率与总对流散热一致；局部元件功率的网格积分等于声明值。
3. **数值收敛**：缩小时间步长、细化网格后，温度指标应稳定；记录迭代残差和能量收支，不把求解器退出码当作物理验证。
4. **交付完整性**：视频全帧解码成功，字节数符合宿主限制，摘要哈希正确，失败不能写成功清单。
5. **回归和发布**：原有机械求解器回归、toolbox 回归、构建器 `--check`、隔离环境中的 PCB/机械烟测全部通过；发布后确认活动摘要与版本，并验证旧任务仍固定原摘要。

验收记录和版本号在 [发布说明](release-1.4.0.md) 中更新。
