# 仿真关键数据需求与验收样例

本文把一次单摆周期问题概括为可复用的验收场景，并扩展出其他物理域的定量需求。原始消息和账号信息不进入仓库。下文的“现有”只表示截至本文件编写时，源码提供了相应求解或查询路径；它不表示已经完成了 QQ 端的端到端交付。

## 数据答复的共同约定

每个数值答复应同时给出：物理量及 SI 单位、模型及关键输入、测量对象、时间窗口、事件/统计量的精确定义、求解步采样间隔、数据来源、质量门结果。事件时间给出相邻样本括住的区间；未观测到事件时给出观察窗口，不能说“永不发生”。理论公式、由已保存序列离线计算的值和求解器原生观测值须分别标明来源。数值质量门失败时不得输出看似可信的物理结论。视频仅用于展示，不用视频帧补测物理数据。

下面使用四种能力标记：**现有查询**（已有结构化查询或诊断）、**可离线计算**（已有经验证的求解步序列，但缺少专用答复字段）、**待新增接口**（需要新指标或事件归约）、**当前模型不支持**（需要新的物理模型，不能用现有量冒充）。“可离线计算”也需要将计算过程、单位和质量检查接入正式数据接口，才算完成群聊场景的自动答复。

## 基准需求：单摆周期

输入：理想平面单摆，摆长 `L=1.0 m`，初角 `+30°`（从世界向下方向朝 `+X`，即 `π/6 rad`），初始角速度 `0 rad/s`，重力 `g=9.8 m/s²`，无阻尼；观察至少三个完整往复。**实测周期**定义为从正侧静止释放到第一次再次到达正侧转折点的时间差。也可以用连续两次“从正角向负角过零”作为等价的每周事件，但必须注明采用了哪种定义；不能把第一次过零或到达对侧当成一整周。

可复现的参考配置为 `physics_system` 的 `pendulum`、`duration=8 s`、`dt=0.002 s`。小角度公式给出 `T₀=2π√(L/g)=2.007089923 s`。对理想无阻尼摆，30° 的完整振幅修正为 `T=4√(L/g) K(sin(15°))=2.042030945 s`，其中 `K(k)=∫₀^(π/2)(1−k²sin²φ)^(-1/2)dφ`。这两个数是**解析参考**，不可标为求解器实测。

本机无视频诊断运行在上述配置下通过了数值质量门；连续同向过零的三段间隔分别约为 `2.042030874 s`，均值为 `2.042030874247 s`。把 `dt` 减半到 `0.001 s` 后，均值为 `2.042030927595 s`，两者差约 `5.33×10⁻⁸ s`。现在 `bob1-period` 已成为单摆工厂的预声明查询，返回同向过零事件、周数、采样括区、实测周期和独立标记的解析参考；完整工具箱离线运行也通过了视频及数值质量门。`pendulum_report` 仍专注角度、能量与杆长误差。正常运行的 QQ 桥已部署此数据回复，但尚未向群里发送新测试消息；“释放到同侧转折”和“同向过零间隔”的直接数值交叉检查仍可作为后续增强。

建议的单摆周期答复字段是：`measured_period_s`、`cycle_definition`、`cycle_count`、`event_times_s`、`event_time_brackets_s`、`small_angle_reference_s`、`finite_amplitude_reference_s`、`dt_s`、`window_s`、`quality_gate`、`source`。理论项的来源标为 `analytic_reference`，实测项标为 `solver_macro_steps`。若窗口内不足两个相同相位事件，返回 `insufficient_cycles` 及具体理由，不估计周期。

## 代表性用户要求

这些话术均为重新撰写的验收提示，不是群聊原文。测试输入需要补全表内所指的长度、质量、初态、边界或热参数；缺少影响结果的参数时应问清或明确标注示例假设。

### 摆与连接系统

| ID / 示例要求 | 输出量及单位 | 当前能力 | 验收方法与边界 |
| --- | --- | --- | --- |
| P01：给出上述 30° 单摆的实测周期，并与两个理论周期对照 | 三个周期，s；相对差，% | 现有 `bob1-period` 查询与解析参考；相对差可由返回值计算 | 用同相位事件求周期、列出返回侧与周数；比较上节参考值，做 `dt/2` 复算并报告杆长和能量误差。 |
| P02：把小角单摆的长度改为 1、2、4 m，分别测周期 | `T(L)`，s | 每次重建单摆并查询 `bob1-period` | 每个长度重新准备运行；核对 `T/√L` 在相同 `g` 下近似不变，并给出每组 `dt` 及采样事件。不能把一个场景的结果改标签复用。 |
| P03：单摆释放后第一次穿过最低点是什么时刻 | 首次角度过零时间，s | 现有查询可用 `bob1-x` 序列；专用角度事件待新增 | 确认初角为正、过零方向为负，并报采样时间括区。若使用 `x=0`，说明只对固定竖直锚点的平面摆等价。 |
| P04：无阻尼单摆每周期的最大摆角有衰减吗 | 正侧峰角序列，rad；峰值差，rad | 可离线计算 | 以每个同侧转折点定义峰值，检查能量漂移、杆长误差和 `dt/2` 稳定性；数值漂移不得解释成物理阻尼。 |
| P05：双摆两根杆各自的角度、末端速度与总机械能如何变化 | `θ₁(t),θ₂(t)`，rad；速度，m/s；能量，J | 现有速度查询及 `pendulum_report`；角度需离线计算 | 第二杆角为**世界绝对角**，不是相对第一杆的关节角；按完整求解步序列校验杆长残差和能量漂移。 |
| P06：仅把双摆第二杆初角微调，多久后两条末端轨迹相距 10 cm | 分离距离，m；首次采样时刻，s | 现有 `compare_pendulums` 离线分析 | 两次运行质量、质量参数、摆长、重力、观察窗口一致；只比较共同宏步，做 `dt/2` 对照；有限窗口分离不能称为 Lyapunov 指数或混沌证明。 |
| P07：三杆串联摆的“周期”是多少 | 必须先定义特定杆/摆球的返回事件；再给 s | 待新增接口；通用连接场景与专用摆工厂能力不同 | 三杆系统可有多个频率或非周期运动，不能无条件报一个“系统周期”。先明确观测量和返回容差；窗口内不重复则报未测得。现有注册摆工厂和 `pendulum_report` 只覆盖一、二杆。 |
| P08：带轴摩擦的摆振幅半衰期是多少 | 包络半衰期，s | 当前模型不支持该物理要求 | 注册摆模型无轴摩擦；不能把理想摆的数值能量损失当阻尼。只有增加并验证阻尼模型后才能回答。 |

### 三体与轨道

| ID / 示例要求 | 输出量及单位 | 当前能力 | 验收方法与边界 |
| --- | --- | --- | --- |
| G01：这组三体在给定 20 s 内是否始终留在半径 5 m 内且两两不小于 5 cm | 最大质心半径、最小两体距离，m；判据状态 | 现有 `nbody_stability` | 申明完整观察窗口、阈值及每步采样；同时报告整个窗口的能量和动量漂移。只作有限窗口判定，不称“永久稳定”。 |
| G02：指定两颗天体第一次相距不到 10 cm 在什么时候 | 中心距，m；首次时间括区，s | 现有 `center_distance` + `threshold` | 两个实体 ID 明确，阈值 `lte 0.1 m`；初态已满足与运行中首次达到要分开表述；距离是点质量中心距，不是表面距离。 |
| G03：三体计算的能量和总动量守恒到什么程度 | 最大相对能量漂移，1；最大动量漂移，kg·m/s | 现有 `nbody_stability` 诊断 | 使用闭合、无外场的点质量场景；核对全窗口峰值而非仅末态；将数值完整性和几何判据分别报告。 |
| G04：某颗天体绕质心一圈用了多久 | 自定义方位返回时间，s | 待新增接口 | 先约定观测平面、参考方向、绕行方向和完整 `2π` 绕数，再从求解步轨迹判定；若未完成一圈返回 `not_observed`。一般三体没有共同固定轨道周期。 |
| G05：三体相撞时的冲击力峰值是多少 | 力，N | 当前模型不支持 | 现有三体是软化的引力点质量，没有接触面、碰撞冲量或力峰测量；接近距离不能冒充碰撞力。 |

### 流体与颗粒

| ID / 示例要求 | 输出量及单位 | 当前能力 | 验收方法与边界 |
| --- | --- | --- | --- |
| F01：水滴在地面投影达到 1 cm 扩散半径用了多久 | `spread_radius`，m；阈值时刻，s | 现有 `spread_radius` + `threshold` | 指定投影平面和固定原点；指标是**全部粒子中心的最远投影距离**，含飞溅粒子，不是接触足迹。对 `dt` 和粒子间距分别做敏感性检查。 |
| F02：液滴质心高度与质心运动速度随时间如何变化 | 高度，m；速度大小，m/s | 现有 `centroid`、`speed` 序列 | 用求解步观测，检查单位和采样窗口。`speed` 是平均速度向量的模，不是所有粒子的平均速率。 |
| F03：液体中最快那颗粒子的速度是多少 | 最大粒子速率，m/s | 待新增接口 | 需要逐步归约每颗模拟粒子的速率，并标明时间和所属实体；不得把已有质心速度或视频估速替代。 |
| F04：水滴真实接触足迹半径和动态接触角是多少 | 足迹半径，m；接触角，° | 当前模型不支持可靠定量答复 | 现有粒子扩散半径包括空中液滴，黏附只是视觉润湿近似；没有已校准的接触线/角模型。可以报告 F01，并说明定义差异。 |
| F05：水流撞击障碍物的瞬时压力分布和总阻力是多少 | 压力，Pa；力，N | 当前模型不支持可靠定量答复 | 现有视觉单相流体及查询不提供经校准的壁面压力和载荷；流体形状或质心轨迹不能证明工程级受力。 |

### 碰撞、滑块与弹簧

| ID / 示例要求 | 输出量及单位 | 当前能力 | 验收方法与边界 |
| --- | --- | --- | --- |
| C01：同一导轨上的两个滑块何时分离至少 1 cm 并持续 0.1 s | 面间隙，m；确认时间，s | 现有 `surface_gap` + `threshold`/`hold_for` | `gap >= 0.01 m`，不能用 `gap >= 0` 代表已分离；报告首次括区与持续条件的确认时刻。 |
| C02：两个刚性球第一次接触在什么时候 | 表面间隙，m；首次括区，s | 现有球形 `surface_gap` + `threshold` | 初始间隙应为正，首次 `gap <= 0`；球的间隙是中心距减半径和。采样步内短暂接触可能漏测，应注明。 |
| C03：碰撞前后的法向相对速度与实测恢复系数是多少 | 速度，m/s；系数，1 | 待新增接口 | 需要有符号法向速度与接触事件两侧的状态；现有标量 `speed` 无法确定方向，也不能把配置的恢复系数当成实测值。 |
| C04：碰撞瞬间最大接触力是多少 | 力，N | 当前模型不支持该量 | 理想刚性碰撞给冲量/速度变化而非有限接触持续时间中的力峰；必须先建立接触顺应性及时间分辨率。 |
| C05：每根线性弹簧的伸长、轴向力和储能随时间如何变化 | 伸长，m；力，N；能量，J | 现有连接查询 | 验证 `F=kΔL+c v_axial` 的符号约定和 `E=½kΔL²`；断裂后力与储能为零，但长度仍是几何量。 |
| C06：哪些独立点质量弹簧在什么时候断开 | 每条弹簧断裂时间，s 或 `null` | 现有独立连接诊断 | `connection_break_times_s` 按连接顺序映射 ID；核对断裂长度严格超过 `(1+阈值)×原长`，未断裂为 `null`。混合耦合连接目前不支持该断裂规则。 |
| C07：含非线性、随机断裂弹簧、球间碰撞和摩擦的整张大网络，给出所有轨迹与断裂时间 | 各球轨迹，m；断裂时刻，s；能量，J | 当前模型不支持该组合 | 现有独立弹簧是理想线性轴向模型，只有指定的确定性拉伸断裂，无独立网络球间碰撞、随机阈值或完整高精度多体轨迹数据接口；应逐项说明缺口，不做静默删减。 |

## 新数据接口的优先验收顺序

1. **P01/P02/P03**：`bob1-period` 已提供完整周期、同向过零事件及解析参考；下一步把首次角度过零与同侧转折事件做成独立查询，并完成 P02 批量比较。现有真实问题可直接检验价值。
2. **B03/C03/G04**：给时序数据增加声明式事件与有符号物理量；这些要求不能从单个最终数值可靠回答。
3. **F03/P07**：补实体内归约和用户指定的返回事件，同时拒绝“任意多自由度系统只有一个周期”的含糊问题。
4. **模型边界案例**：F04/F05、C04/C07、G05、B05、P08 必须返回具体不能模拟的理由及可选的有定义替代指标；不得生成假定为实测的数值。

每个新增指标至少用解析/守恒基准、时间步或网格细化、失败/未观测状态、质量门拒绝路径和保存结果重新读取验证。QQ群集成验收应只在真实用户请求上发送一次结果；失败案例的自动复测只在本机进行。
