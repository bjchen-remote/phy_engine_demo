# Physics toolbox 1.3.3

This release starts from the established waterball simulation and retains the native liquid self-gravity, finite liquid-launch, mesh-contact, particle-grid and mesh-audit improvements. It keeps liquid solver states unchanged and adds a full-trajectory, constant-rate slow-motion presentation for liquid scenes. The verified real-time clip remains available inside the task artifacts.

Water video metadata reports physical duration, playback duration and `time_scale_to_physical`; numerical results continue to use only the original solver trajectory.
