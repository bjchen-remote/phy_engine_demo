# Physics toolbox 1.2.4

本版让宿主 Agent 通过结构化 API 组合物理模型、生成完整视频并读取预先声明的观测量。
样例只是建模起点；能力范围以 `physics_capabilities` 和 `physics_prepare` 为准。

- **自主建模**：提供系统、网格、液体、约束、补丁、预估、校验和查询接口；准备后的规范化模型是执行依据。
- **视频优先**：普通视频默认 `visual`，精度警告不会单独阻止交付。定量与稳定性问题使用 `strict`；未通过数值检查时拒绝输出定量答案。
- **近距离引力**：按软化后的自由落体和穿越时间细分积分步长，保留用户初态、物理时长和输出采样时钟。
- **大小受控**：视频超出宿主字节上限时，仅重新编码已保存帧；保留全部帧与播放时长，不重算物理。呈现失败与物理失败分别报告。
- **独立发布**：宿主传入任务、工作目录和资源限制；模块按内容摘要发布，运行中的任务保留原版本。每分钟是常规响应目标，实际硬预算由宿主决定。

建模入口见 [模块说明](../toolboxes/physics/README.md)，宿主集成见
[任务协议](../toolboxes/PROTOCOL.md)，内部职责见 [架构](architecture.md)。
手册、样例与打包引擎由构建器从公共源文件同步，避免维护两套实现。

验收：独立公开检出通过 389 项引擎回归和 13 项模块回归，构建清单与预编译文件摘要校验通过。
回归覆盖精度警告与严格查询隔离、近距离引力、完整时长、视频字节预算、慢放帧数、任务路径限制和版本完整性。
另验证完整的 20 秒轨道视频流程以及压缩后的逐帧解码；测试不向消息平台发送内容。

当前预编译模块面向 macOS arm64。视觉验收通过不代表科学精度认证；这些模型不等同于任意现实物理。
模块测试不代表消息平台连续在线或用户端播放已经验收。图片建模属于引擎能力，文本宿主仍须自行提供附件接入。
