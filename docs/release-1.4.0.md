# Toolbox 1.4.0: PCB thermal and prescribed power

发布日期：2026-09-24。

## 交付内容

- 在现有 `physics` toolbox 中增加独立 PCB 热求解域，保留原有机械 `scene-v1`、C11 数值内核与宿主 v1 任务协议。
- 支持稳态和瞬态二维等效板面传热、x/y 各向异性等效导热、上下表面对流、矩形元件功率和绝热板边界。
- 输出元件功率图、温度图、最低/平均/最高温度、瞬态累计对流散热、能量平衡、求解器残差和经完整解码的视频。提供结构化准备、校验与结果查询。
- 已准备模型加领域标签，PCB 与机械场景不会互相误用；既有 toolbox 活动指针可同时提供两类能力。

## 模型范围

求解器使用保守有限体积离散，瞬态采用后向欧拉，线性方程用预条件共轭梯度法。`power_w` 是预先给定的热耗散，不由电路电压、电流推导。首版不解析走线、过孔、封装内部、厚度方向温差、风道或辐射。实际板材等效导热系数和对流系数需针对硬件校准；[设计与验收依据](pcb-thermal-design.md) 列出方程和门禁。

## 验收记录

- PCB 数值测试：9 项，覆盖单元解析解、二单元导热网络、瞬态储能、绝热、功率守恒、对称性、各向异性、网格和时间步收敛及非法输入。
- PCB 视频测试：2 项，包含真实 H.264 编码、逐帧解码和失败路径。
- PCB 查询边界回归：1 项，覆盖近右边界舍入与超大整数输入。
- Toolbox 测试：24 项，通过；其中 2 项在原生 macOS sandbox 中验收 PCB 模型准备、probe、求解、视频、数值查询与跨领域状态清理。
- 机械引擎回归：415 项，通过；QQ 宿主回归：277 项，通过。当前已启用的 1.3.3 机械优化已同步到候选包；原生自引力与网格场景共 21,853 个数值和结构输出与启用包完全一致。
- `toolboxes/build_physics.py --check` 通过；发布包哈希覆盖 PCB 求解器、视频代码、示例和现有包入口。PCB 求解域与机械内核相互独立。

## 使用与发布

PCB 模型示例位于 [`toolboxes/physics/pcb_thermal_demo.json`](../toolboxes/physics/pcb_thermal_demo.json)。使用现有 `physics` 活动包的 `pcb_example`、`pcb_validate`、`pcb_prepare` 操作准备，再由 `physics_simulate` 执行。宿主 macOS 环境还需要 `ffmpeg` 与 `ffprobe` 供 PCB 热图编码和完整解码。常规机械视频不增加此依赖。

仓库版本由 Git 提交与 `v1.4.0` 标签标识；本机 registry 由内容摘要固定并原子激活。实际标签、远端发布和活动摘要以发布记录为准。
