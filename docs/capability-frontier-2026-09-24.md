# 公开能力边界与下一步（2026-09-24）

按用户价值和实现成本排序。`physics_prepare` 返回 `ready_to_simulate=true`，只证明**提交的场景可执行**，不证明它与用户要求的机制或精度吻合。Agent 选示例时必须核对驱动、物体、持续时间和测量量；关键机制被替代时，先说明差别并取得近似授权。

1. **Agent 路由｜持续倒水、行驶涉水。** 现状：目录中的倒水用有限水团，涉水用静止车体（[目录](../physics_demo/catalog.py)）。本轮已给八个高风险示例标注“实际／缺失机制”；下一步建立中英文请求判定集。验收：明确要求持续供水、车辆平移或铅水冷却凝固时，Agent 不把现有近似报告为满足原请求。

2. **渲染｜指定侧视、跟拍和主体画幅。** 现状：每段视频只有固定自动取景，场景无相机参数（[能力声明](../physics_demo/io/schema.py)）。最低实现：在物理结果之外提供视角、目标和画幅控制。验收：同一轨迹可生成两个视角，轨迹／诊断／查询不变，主体在指定画幅内。

3. **观测｜撞击载荷与杆绳反力。** 现状：有弹簧本构力，没有逐时接触力或杆绳反力；汇总冲量不能当瞬时峰值（[指标](../physics_demo/analysis/queries.py)、[耦合](../agent/physics-simulation/references/coupling.md)）。最低实现：按对象、宏步记录有方向的冲量及时间窗平均力。验收：碰撞冲量符合动量变化，静止支撑平均力接近重量，并报告时间步敏感性。

4. **建模／求解｜前进车辆、转轮、铰链。** 现状：`kinematic` 网格仅恒速平移；刚体无公开驱动转矩，固定 pivot 仅限单体主轴（[网格](../agent/physics-simulation/references/mesh-modeling.md)、[刚体](../agent/physics-simulation/references/coupling.md)）。最低实现：先提供有界规定刚体轨迹，再加入双刚体铰链。验收：位置、姿态和角速度吻合规定值，关节残差与穿透受控。

5. **建模／求解｜持续喷嘴与排水。** 现状：粒子在初态生成，喷泉与弹道喷发只有有限水量（[工厂](../physics_demo/systems/__init__.py)、[喷发](../agent/physics-simulation/references/ballistic-burst.md)）。最低实现：有容量上限的定时粒子源／汇及入出流账本。验收：累计注入量减排出量等于库存变化；改变宏时间步后流量和账本保持稳定。

6. **求解｜漂浮、吃水和流体载荷。** 现状：混合路线有离散双向接触，没有动态刚体／网格的流体压力边界，不能声称校准浮力（[耦合](../agent/physics-simulation/references/coupling.md)）。最低实现：先对球／盒刚体增加移动压力边界及成对反力。验收：静水吃水符合排水质量关系，净力闭合，并做粒距、时间步细化。

7. **材料求解｜油水分层、气泡。** 现状：液体预设共用压力相和参考密度，空气未解析（[预设](../agent/physics-simulation/references/liquid-presets.md)）。最低实现：先限定两种不混溶液体的密度和界面；气泡另立阶段。验收：静置分层、各相质量守恒和界面位置随粒距细化稳定；不能只靠换颜色。

8. **拓扑求解｜切布、断裂、真实冲蚀。** 现状：网格拓扑固定，沙水侵蚀是定性代理（[网格](../agent/physics-simulation/references/mesh-modeling.md)、[沙雕](../physics_demo/catalog.py)）。最低实现：先做受限布料断边、新边界碰撞与渲染；沉积物转移另建模型。验收：切线两侧分离、拓扑有效，质量和能量变化有账本。

第一项的机器标签已完成，下一步优先做中英文路由验收、相机控制和逐对象平均力。涉及新物理状态的 4–8 须同步更新场景合同、预算、求解、观测、渲染和独立验收；质量门通过只说明所声明模型的运行结果合格。
